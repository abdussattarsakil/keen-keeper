# 👥 KeenKeeper — Keep Your Friendships Alive

KeenKeeper is a responsive friendship tracking web application where users can manage and maintain meaningful connections with friends. The app helps users track communication history, monitor contact goals, and stay connected through calls, texts, and video interactions.

## 🛠️ Technologies Used

* React.js
* React Router
* Tailwind CSS
* DaisyUI
* React Toastify
* Recharts
* React Icons

---

## ✨ Main Features

### 👥 Friend Management

* View all friends in a responsive card layout
* See friend status, tags, and contact information
* Navigate to detailed friend profiles

### ⚡ Quick Check-In System

* Log Call, Text, and Video interactions
* Automatic timeline updates
* Toast notifications for interactions

### 📜 Timeline Tracking

* View complete interaction history
* Filter timeline by Call, Text, or Video
* Timeline entries include date, title, and icons

### 📊 Friendship Analytics

* Pie chart visualization using Recharts
* Track communication activity statistics

### 📱 Fully Responsive Design

* Optimized for mobile, tablet, and desktop devices

### ❌ Error Handling

* Custom 404 page
* Loading spinner while fetching data

Install dependencies:

